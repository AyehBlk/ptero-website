Scientific validation

Participate in benchmarking

Researchers interested in contributing to a future PTERO publication can express interest in a structured benchmarking study. The intended workflow will use a defined test protocol and a benchmarking package to collect comparable performance and reproducibility measurements.

Proposed measurements

Input format and dataset size, software and environment versions, processing durations, peak memory use, workflow completion status and predefined output checks.

Privacy & consent

Participants should be able to review the benchmark report before sharing it. Do not automatically transmit raw data, identifiers, proprietary sequences or sensitive paths.

Research contribution

Contributions may support benchmarking and manuscript preparation. Authorship or acknowledgements will depend on actual contributions and the research team’s agreed criteria; participation alone does not guarantee authorship.

Status: The automated benchmark runner and results-submission workflow are planned, not yet available for download.
