PTERO — Proteomics Tool for Exploratory Research & Optimization is available as a public Windows beta. The ZIP archive contains the application executable and its supporting files. No separate Python installation is required.

Official v0.2.0 pre-release. The download is hosted on GitHub Releases; size shown is approximate.

Install and run

  1. Download the ZIP archive using the button above.
  2. Right-click the downloaded ZIP and select Extract All.
  3. Open the extracted PTERO_v1_rc folder.
  4. Double-click PTERO_v1_rc.exe to launch PTERO.
  5. Keep the _internal folder beside the executable. Do not run the application from inside the ZIP.
Public beta notice: PTERO is under active development. Back up original data before testing.
