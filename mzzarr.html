Mass spectrometry data format

Introducing mzZarr v1.0

A proposed vendor-independent mass spectrometry format based on Zarr v3 and Parquet.

mzZarr defines the data format. PTERO provides its Python and Windows reference implementation.

Format structure

mzZarr stores peak measurements in Zarr arrays and spectrum-level metadata in Parquet.

  • peaks/mz — float64 peak mass-to-charge values
  • peaks/intensity — float32 peak intensities
  • offsets — int64 spectrum boundaries
  • spectra.parquet — spectrum metadata, including scan_index and ms_level
  • peaks/ion_mobility — optional aligned float32 ion mobility measurements

Specification status

Read the frozen mzZarr v1.0 specification on GitHub

The frozen mzZarr v1.0 specification is publicly available under the v1.0 tag in the mzZarr GitHub repository.

mzZarr is a proposed format, not a HUPO-PSI-endorsed standard. Independent cross-language interoperability has not yet been demonstrated.

Relationship to PTERO

mzZarr defines the data format; PTERO provides a reference implementation. The currently available Windows desktop download is an evaluation beta and may predate some specification changes.
