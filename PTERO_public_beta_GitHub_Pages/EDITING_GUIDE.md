# Editing PTERO website

Open `tutorials.html` to edit workflow guidance. The separate `mzml-conversion.html` page contains the Thermo RAW to mzML walkthrough. PDFs live in `docs/`.

To add a video later, edit the single Video library section of `tutorials.html`. For YouTube videos, use an iframe with an embed URL from `https://www.youtube-nocookie.com/embed/VIDEO_ID` and a meaningful title.

For benchmarking, do not advertise automatic reporting until a tested, opt-in benchmark runner and a secure submission method exist.

Deploy all files and folders together to GitHub Pages.

MSConvert guide: edit mzml-conversion.html and keep docs/PTERO_mzML_Conversion_Guide.pdf synchronized. Record actual filters and their order in any benchmarking report.
