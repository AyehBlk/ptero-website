Step 01

Prepare your raw data

Bruker .d: PTERO can work directly with supported Bruker .d directories. Keep the complete directory intact.

Thermo .raw: First convert your files to .mzML using a compatible tool such as ProteoWizard MSConvert.

View the mzML conversion tutorial → Download conversion PDF

Step 02

Create a PTERO Dataset

Open Raw data → Create PTERO Dataset. Supply the full path to the input .mzML file or Bruker .d directory, or use the application’s file/directory picker. Select a separate output location for the new PTERO Dataset.

One sample

Select the path to one .mzML file or one complete .d directory. Choose a new destination for its PTERO Dataset, then start conversion.

Multiple samples

Organize each sample as a separate .mzML file or .d directory. Where your installed PTERO version provides multi-input selection, select all supported inputs; otherwise convert each sample separately and keep the outputs clearly labeled.

Example Windows paths: C:\Data\Sample01.mzML or D:\Experiment\Sample01.d. Never choose the original raw-data directory as an output destination. The exact batch-selection controls may vary by PTERO build.

Step 03

Explore spectra

Load a PTERO Dataset and inspect the available visualizations. A mass spectrum displays ion signal versus mass-to-charge ratio (m/z); a chromatogram displays signal over retention time.

Chromatograms & XICs

Inspect signal over time, investigate elution profiles and compare targeted ions using extracted-ion chromatograms (XICs).

Mass spectra

Inspect precursor and fragment-ion patterns, signal quality and candidate peptide evidence where available.

Feature maps & QC

Explore feature distributions, retention-time patterns and quality-control indicators. Ion mobility views are relevant only for datasets containing mobility information.

Educational documentation explaining each plot, its controls, and common interpretation pitfalls is under development.

Step 04

Identification results

Currently supported workflow: MaxQuant. Export or locate MaxQuant’s combined/txt results directory. Use the compatible MaxQuant text files requested by your PTERO version.

Protein-level results

proteinGroups.txt contains protein-group identifications, annotations and associated quantitative columns. This is the primary protein-level result table.

Peptide & spectrum evidence

MaxQuant may also provide peptides.txt, evidence.txt and msms.txt. These contain different peptide, feature and MS/MS evidence; load only those that the corresponding PTERO control accepts.

Optional protein FASTA

When PTERO offers FASTA import, supply the .fasta or .fa protein-sequence database used for the original MaxQuant search. FASTA is plain text with > identifier lines followed by amino-acid sequences. Matching database identifiers help associate protein sequences with results and support sequence-oriented inspection where implemented.

Use the identification tab to inspect protein and peptide tables, investigate supporting evidence and, where available, review sequence coverage, annotated spectra and linked chromatograms. Converting raw data does not itself perform protein identification.

A detailed guide to interpreting identification scores, coverage, peptide-to-protein relationships and PTERO controls is under development. Exact file requirements should be confirmed against the current application build.

Step 05

Differential protein abundance

Currently supported source: MaxQuant protein quantification. Start with combined/txt/proteinGroups.txt, which commonly contains per-sample Intensity SAMPLE and LFQ intensity SAMPLE columns. Make sure the expected sample columns exist and correspond to your experimental design.

Intensity

Protein signal estimates from the MaxQuant intensity columns. Useful for examining measured signal and workflows where appropriate normalization is handled explicitly.

LFQ intensity

MaxQuant label-free quantification estimates, produced when LFQ is enabled in MaxQuant. Designed to improve between-sample protein-level comparisons under its LFQ assumptions; missing or zero values still need careful handling.

Why both? They answer related but different analytical needs: raw-style intensity values let researchers inspect signal and assess normalization choices; LFQ intensity values provide MaxQuant’s processed label-free estimates for comparative analysis. Do not treat the two as interchangeable or mix them in the same analysis.

Choose the appropriate measurement type, assign samples to biological groups, select a comparison, inspect missing values and the statistical settings, then review the resulting tables and plots. Biological replicates and a sound experimental design are essential for meaningful inference.

More educational documentation on normalization, missing values, fold changes, statistical tests and interpretation is under development.
