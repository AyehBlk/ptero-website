Architecture

The PTERO Dataset

PTERO uses a hybrid Zarr / Parquet working container. Zarr stores peak arrays (m/z, intensity, optional ion mobility) and spectrum offsets, while Parquet stores spectrum-level metadata. The structure is designed for selective access to large datasets without requiring all peaks to be loaded into memory at once.

Research objective: evaluate whether this design improves practical handling of large 3D and 4D proteomics runs on standard computers. Comparative performance claims are being investigated through benchmarking and validation.

Technical architecture & scientific publication

The PTERO Dataset is being developed as part of ongoing research into efficient representation, organization, and interactive exploration of mass spectrometry data. Its hybrid storage model separates numerical peak arrays from structured spectrum-level metadata to support selective data access.

A scientific manuscript is currently in preparation. It is intended to describe the architecture and implementation, conversion workflow, data organization, and benchmarking and validation methodology. Detailed technical results will be presented in the manuscript once available.
